# E-commerce Analytics Platform

## 1. Project Overview

The **E-commerce Analytics Platform** is a data analytics project built using **Python, SQL, Power BI, and Excel** to analyze e-commerce business performance.

The project processes customer, product, order, order-item, and payment data to generate useful business insights. It helps understand revenue trends, product performance, customer purchasing behavior, order statuses, and profitability.

The project demonstrates practical skills in data cleaning, data validation, database management, SQL analytics, Python automation, data visualization, and business intelligence reporting.

## 2. Project Objectives

- Analyze e-commerce sales and revenue performance.
- Identify top-performing products and product categories.
- Understand customer purchasing behavior.
- Track completed, cancelled, and returned orders.
- Calculate revenue, profit, profit margin, and average order value.
- Build a structured relational database using SQL.
- Automate data processing and reporting using Python.
- Prepare an interactive business dashboard using Power BI.
- Convert raw data into meaningful business insights.

## 5. Dataset Description

The project uses sample **synthetic e-commerce data** created for learning and demonstration purposes. It does not represent real customers or actual company transactions.

The supplied dataset contains five CSV files.

| Dataset | Number of Records | Description |
|---|---:|---|
| Customers | 250 | Customer details |
| Products | 16 | Product names, categories, and pricing information |
| Orders | 1,000 | Order dates, customers, and order statuses |
| Order Items | 1,454 | Products and quantities associated with orders |
| Payments | 1,000 | Payment amounts, methods, and statuses |

### Dataset files

- `customers.csv` – customer information.
- `products.csv` – product details and pricing.
- `orders.csv` – order-level information.
- `order_items.csv` – individual product lines within orders.
- `payments.csv` – payment transaction records.

The datasets are connected through identifiers such as customer IDs, product IDs, and order IDs.

## 7. Database Schema

The project uses a relational database with five main tables.

### 7.1 Customers

Stores customer information.

Important fields include:

- `customer_id` – unique customer identifier.
- Customer name and contact-related fields included in the dataset.
- Other customer attributes supplied in the CSV file.

### 7.2 Products

Stores product information.

Important fields include:

- `product_id` – unique product identifier.
- Product name.
- Product category.
- Product price and cost information.

### 7.3 Orders

Stores order-level information.

Important fields include:

- `order_id` – unique order identifier.
- `customer_id` – customer associated with the order.
- Order date.
- Order status.

### 7.4 Order Items

Stores individual products associated with each order.

Important fields include:

- Order identifier.
- Product identifier.
- Quantity.
- Item price and other supplied order-line attributes.

### 7.5 Payments

Stores payment information.

Important fields include:

- Payment identifier.
- Order identifier.
- Payment amount.
- Payment method and payment status.

The exact column definitions and relationships are provided in `sql/schema.sql`.

## 12. Key Business Metrics

### Total Orders

Counts orders according to the selected order population.

### Completed Revenue

Measures revenue associated with completed orders according to the project's business rules.

### Completed Profit

Calculates profit from completed sales using the available selling-price and cost information.

### Profit Margin

Shows profit as a percentage of revenue.

```text
Profit Margin (%) = (Profit / Revenue) × 100
```

### Average Order Value

Measures average revenue per completed order.

```text
Average Order Value = Completed Revenue / Completed Orders
```

### Monthly Revenue

Groups completed revenue by month to reveal changes in sales performance.

**Important:** Revenue, profit, and order metrics must be calculated consistently. Cancelled or returned orders should be handled according to the business rules and the definitions in the supplied SQL queries and DAX measures.

## 13. Installation and Setup

### Prerequisites

Install the following software:

- Python 3.10 or later.
- Visual Studio Code or another Python editor.
- Git, if you want to upload changes using Git commands.
- Power BI Desktop, if you want to build the interactive dashboard.

### Step 1: Download the project

Download or clone the repository from GitHub.

To clone it, open a terminal and run:

```bash
git clone https://github.com/Balu200512/ecommerce-analytics-platform.git
```

Move into the project folder:

```bash
cd ecommerce-analytics-platform
```

If you downloaded the ZIP instead, extract it and open the extracted folder in VS Code.


## 15. How to Explore the Database

The generated SQLite database is named:

`ecommerce_analytics.db`

You can inspect it using a SQLite database browser or Python.

Example Python code:

```python
import sqlite3
import pandas as pd

connection = sqlite3.connect("ecommerce_analytics.db")

query = """
SELECT name
FROM sqlite_master
WHERE type = 'table'
ORDER BY name;
"""

tables = pd.read_sql_query(query, connection)
print(tables)

connection.close()
```

Run this code from the project directory after generating the database. It lists the tables that exist in the database.

To explore the analytical SQL queries, open `sql/analytics_queries.sql`.
